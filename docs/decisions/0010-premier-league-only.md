# 0010 — Scope is the Egyptian Premier League only

**Context.** Second-division crews reuse names that also appear in the
Premier League ("محمود ناجي" refereed in both on nearby dates).

**Decision.** Only Premier League matches are loaded, starting with season
2026/27.

**Consequences.** Name collisions stay rare and resolvable; the league size
(20 teams, 10 matches per round) is a built-in check on every round.
