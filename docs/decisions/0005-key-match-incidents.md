# 0005 — The case library covers Key Match Incidents only

**Context.** Recording every foul would mean 1,000+ entries for 50 matches,
almost none with an official answer, collected by hand from video.

**Decision.** A case is a decision that can change a result: a penalty
(given or appealed), a red card (direct or second yellow), a goal with a
question mark (offside, foul, handball), any VAR involvement, or mistaken
identity. Roughly 2–4 per match. Routine fouls belong to the "what we could
do with your data" part, because they need the committee's assessor data.

**Consequences.** A collectable library (target 100–150 cases for a demo).
Weighting hard cases more heavily (Moaz's idea) is kept for later analysis.
