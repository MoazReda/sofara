# 0003 — Canonical names are the form on EFA crew cards

**Context.** Sources disagree: the referee report uses full four-part names,
the press uses short or nicknamed forms, and the EFA's own crew cards use a
consistent short form every round.

**Decision.** `officials.name_ar` is the name as printed on the EFA crew
cards. Every other spelling is an alias with its source.

**Consequences.** New rounds from the same source load with few new aliases.
Full legal names are still kept (as aliases), so the referee report can be
matched.
