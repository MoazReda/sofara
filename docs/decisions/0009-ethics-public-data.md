# 0009 — Public data is never presented as referee accuracy

**Context.** Public sources describe discipline patterns (cards, penalties)
and opinions. Whether a decision was right needs the committee's internal
assessments, which are confidential.

**Decision.** No number from public data is labelled as a referee's accuracy.
Real referees appear only in a development framing, never in a public
best-to-worst ranking; public outputs are league-level. Synthetic data is
used only as clearly labelled mockups, never for analysis. No scraping
against a site's terms; videos are timestamped links; expert views are
summarised in our own words with a source.

**Consequences.** Some tempting charts are off the table. The demo is credible
to the committee because it shows what public data can and cannot say.
